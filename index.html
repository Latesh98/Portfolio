Smart accessibility system for visually impaired users

computer-visionspring-bootjavatomcat

Final year engineering project. A real-time aid that describes a person’s surroundings out loud so they can move through unfamiliar space on their own.

  • Captures the scene from a live camera feed and identifies objects in frame using image processing and a trained model.
  • Converts detections into spoken descriptions, prioritised so the most relevant obstacle is announced first.
  • Served from a Java Spring Boot backend on Tomcat, with a lightweight browser front end for setup and testing.
  • Built and tuned for latency, since a description that arrives late is worse than none at all.
